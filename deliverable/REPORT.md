# תרגום Audacity 4.0.1 לעברית — דוח עבודה

## 1. מה תורגם

| קובץ | תיאור | מצב |
|---|---|---|
| `share/locale/audacity_he.ts` | קטלוג התרגום הראשי של ממשק Audacity 4 (Qt/QML) | **4,139 / 4,139 הודעות מתורגמות (100%)**, 3,357 מחרוזות ייחודיות |
| `audacity_he.qm` | הקטלוג המקומפל שהתוכנה טוענת בזמן ריצה | נוצר ונבדק (4,139 תרגומים, 0 לא גמורים) |
| `au3/locale/he.po` | הקטלוג הישן (gettext) של מנוע au3 | 1,260 רשומות עודכנו למינוח החדש; השאר נשארו בתרגום הקודם (ראו סעיף 6) |

**כל הקטלוג של Audacity 4 תורגם מחדש מאפס** — לא רק החסר. 1,984 מתוך 1,985 התרגומים שהיו קיימים הוחלפו,
כך שכל הממשק מדבר בשפה אחת ועקבית (קודם היו ערבובים: "הערוך", "היפוך מהתחלה", "הקול שבחזית",
"ייבא תויות", "סרגל כלי התקדמות" וכו').

## 2. איך נשמרה ההקשר הפונקציונלי (ולא "תרגום גוגל")

* נבנה מילון מונחים מקצועי (`glossary.md`) של ~150 מונחי עריכת שמע, ולפיו תורגם הכול:
  track→רצועה, clip→קטע, playhead→ראש השמעה, gain→הגבר, level→מפלס, amplitude→משרעת,
  envelope→מעטפת, fade in/out→עלייה/דעיכה הדרגתית, clipping→קליפינג, latency→השהיה,
  preset→פריסט, label→תווית, attack/release→התקפה/שחרור, threshold→סף, ratio→יחס.
* כל מחרוזת תורגמה לפי **התפקיד שלה בממשק**: כותרת פעולה (תפריט/לחצן) קצרה ופועלית,
  תיאור פעולה (tooltip) במשפט מלא שמסביר מה קורה, הודעת שגיאה עם הפתרון, תווית שדה קצרה.
* הובחנו מונחים שנשמעים דומה אך שונים בתפקוד: Invert≠Reverse (היפוך קוטביות מול היפוך),
  Pan≠Balance (פאן מול איזון), Latency≠Delay (השהיית קלט/פלט מול אפקט השהיה),
  Reverb≠Echo (הדהוד מול הד), Level≠Volume (מפלס מול עוצמת קול).
* הושארו באנגלית רק שמות מוצרים/תקנים/פורמטים: VST3, LV2, LADSPA, Nyquist, FFmpeg, LAME,
  MIDI, MusicXML, MEI, FLAC, Opus, RMS, dB, Hz, Audio Unit, audio.com.

## 3. בדיקות שנעשו (עם פלט)

* **מבנה XML תקין**: `xml.etree` מפרס את הקובץ; 4,139 הודעות, 0 `unfinished`.
* **קומפילציה של Qt**: `pyside6-lrelease audacity_he.ts -qm audacity_he.qm`
  → `Generated 4139 translation(s) (4139 finished and 0 unfinished)`.
  בהרצה הראשונה התברר של-Qt יש לעברית **שתי צורות רבים** ולא שלוש; הצורות תוקנו
  (יחיד/רבים) והקומפילציה עוברת בלי אזהרות.
* **טעינה בזמן ריצה** (Qt אמיתי, לא סימולציה): `QTranslator.load()` → `True`,
  ובשאילתות בפועל: `action/Exit`→`יציאה`, `preferences/Sample rate`→`קצב דגימה`,
  `effects-amplify/Amplify`→`הגברה`, `builtin-effects/Auto Duck`→`הנמכה אוטומטית`,
  `action/Exit`→`יציאה`.
* **שלמות מצייני מקום**: השוואת `%1..%n, %s, %d, %Ld, %Ln` ופקודות Lisp (`~a`, `~%`)
  בין מקור לתרגום בכל 4,139 ההודעות → **0 אי-התאמות**.
* **תגי rich-text** (`<b>`, `<a href>`, `<br>`, `<span>`) נשמרו זהים למקור.
* **קטלוג gettext**: נבנה `.mo` תקין ונבדק בקריאה חיה (`gettext`): `Track`→`רצועה`,
  `Amplify`→`הגברה`, `Noise Reduction`→`הפחתת רעשים`.
* סריקת איכות אוטומטית (`qa.py`): לא נמצאו מחרוזות שנשארו באנגלית בטעות, לא נמצאו
  סימני פיסוק חסרים, ולא נמצאו חריגות מהמילון (ההערות שנותרו הן שמות מוצרים).

## 4. החלטות סגנון

* עברית בלשון רבים/ניטרלי ("בחר", "לחץ") — כמו ההוראות במקור.
* מקף עברי ־ במילים מחוברות (audio.com, דו־שיח, מילי־שניות), מירכאות עבריות „…” וקיצורים בסימן ׳/״.
* **מקשי גישה מהירה (mnemonics)**: סימן ה-`&` הוסר מכל התרגומים העבריים — בעברית
  לא משתמשים בסימון הזה. נשארו רק תווי HTML שחייבים להישאר (`&nbsp;`) והכפילויות
  `&&` שרק מציגות תו `&` בפועל (למשל `Presets && settings`). בדיקה: לא קיים שום
  משתנה/placeholder שמשתמש ב-`&` — ה-`%s/%d/%1..%n` ופקודות ה-Nyquist (`~a`, `~%`)
  אינם קשורים אליו, כך שאין סיכון לשבר מחרוזות.
* מחרוזות מרובות שורות (הודעות אבחון, Nyquist) תורגמו תוך שמירה על מבנה השורות והזחות.

## 5. איך מפעילים

```bash
# 1) התקנה ידנית (מהיר): העתקת הקטלוג המקומפל להתקנה
sudo cp audacity_he.qm /usr/share/audacity4/locale/     # או lib/audacity/locale וכו'
# 2) או בנייה מהמקור עם קומפילציית תרגומים
cmake -B build -DAU_RUN_LRELEASE=ON && cmake --build build
```
לאחר מכן: `Preferences → General → Language → עברית` (השפה כבר רשומה ב-`languages.json`).

## 6. מה עוד לא הושלם — שקיפות

`au3/locale/he.po` הוא קטלוג gettext של מנוע au3. בבדיקה בעץ 4.0.1:
אין `au3/CMakeLists.txt`, ו-`Languages::GetLanguages()` נקרא רק מ-`au3/src/*` הוותיק —
כלומר **Audacity 4.0.1 לא טוען את קובץ ה-`.mo` הזה**; הממשק נטען כולו מ-`.qm`.
לכן תורגם במלואו הקטלוג שבאמת משמש את התוכנה (`.ts`/`.qm`), וב-`.po` עודכנו 1,260
רשומות זהות למינוח החדש. 3,137 הרשומות הוותיקות שנשארו משמשות רק את עץ Audacity 3 —
אפשר להשלים אותן מאותו מילון ובאותה שיטה בלחיצה אחת.

לא בוצעה בדיקה חזותית של ממשק RTL אמיתי: בניית Audacity 4 דורשת Qt6+Conan/CMake עם
עשרות תלויות (במכונה כאן 2 ליבות ו-3GB RAM). הבדיקה נעשתה ברמת הקטלוג ובאמצעות
מנוע התרגום של Qt עצמו.
