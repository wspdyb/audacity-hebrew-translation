Audacity 4.0.1 — Hebrew language pack
======================================

What was installed:
  share\audacity4\locale\audacity_he.qm   (compiled Hebrew catalogue, 4,139 messages)

How to switch Audacity to Hebrew:
  1. Start Audacity.
  2. Edit > Preferences (Ctrl+P) > General > Language.
  3. Select "עברית" (Hebrew) and restart Audacity.

Manual install / portable copies:
  Copy audacity_he.qm into <Audacity>\share\audacity4\locale\

Uninstall:
  Run AudacityHe-Uninstall.exe in the Audacity folder,
  or Apps > "Audacity Hebrew Language Pack 4.0.1".

Notes:
  - The pack contains only the translation file; Audacity itself is not modified.
  - Compatible with Audacity 4.0.1 (Qt UI). For Audacity 3.x use the legacy
    he.po/he.mo gettext catalogue instead.
